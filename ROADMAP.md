1. Подготовить каталог.
Найти или собрать набор товаров — несколько тысяч штук с названием, брендом, категорией, ценой, характеристиками и описанием. Сложить их в базу данных.

2. Сделать простой бэкенд.
Приложение, которое умеет отдавать список товаров и один товар по id. Поиск пока самый примитивный: просто проверка, есть ли слово в названии. Это точка отсчёта.

3. Научить приложение «понимать» текст.
Разбивать названия и запросы на слова, приводить к одному виду (регистр, окончания), выбрасывать мусорные слова. Чтобы «Кроссовки Nike» и «кроссовок найк» сводились к чему-то сравнимому.

4. Построить индекс.
При запуске приложение один раз проходит по всему каталогу и запоминает, в каких товарах встречается каждое слово. Дальше поиск идёт уже по этому индексу и работает мгновенно.

5. Отсортировать результаты по релевантности.
Совпадение в названии важнее, чем в описании; редкое слово важнее частого. Наверху выдачи — самые подходящие товары.

6. Сделать фронтенд.
Привычная вам страница каталога: поисковая строка, список карточек, пагинация. С этого момента проект выглядит как настоящий.

7. Добавить фильтры.
Бренд, цена, категория, характеристики. С подсчётом количества товаров у каждого значения фильтра.

8. Добавить автодополнение.
Подсказки при вводе: слова, категории, бренды, товары.

9. Научиться прощать ошибки пользователя.
Опечатки, неправильная раскладка клавиатуры, транслит, синонимы. «Возможно, вы имели в виду…».
